# 3D-print figures

This folder contains the original `.3mf` print files supplied with the team's project archive. They are **separate from the SolidWorks mechanical assemblies** in the parent folder.

Some character models may have been sourced from outside the project. **Verify each file's original license and attribution before redistributing or reusing it publicly.** Inclusion here does not imply the team created every themed figure or owns the underlying character IP.
